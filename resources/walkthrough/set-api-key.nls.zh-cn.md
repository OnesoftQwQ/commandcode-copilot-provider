CommandCode for Copilot Chat 使用你自己的 CommandCode API 密钥，让丰富的 AI 模型出现在 Copilot 模型选择器中。

只需粘贴一次，之后可通过命令面板更新或移除。

- `Cmd/Ctrl + Shift + P`：打开命令面板
- `CommandCode: 设置 CommandCode API 密钥`：设置或更新 API 密钥
- `CommandCode: 使用 CommandCode 生成提交消息`：生成 Git 提交消息

[获取 API 密钥](https://commandcode.ai)
[设置 API 密钥](command:commandcode.setApiKey)
