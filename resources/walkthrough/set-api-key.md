CommandCode for Copilot Chat uses your own CommandCode API key to make a variety of AI models available in the model picker.

Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `CommandCode: Set CommandCode API Key`: Set or update your API key
- `CommandCode: Generate Commit Message with CommandCode`: Generate Git commit messages

[Get an API Key](https://commandcode.ai)
[Set API Key](command:commandcode.setApiKey)
